## 数据格式

```ts

	{ 
		requestId: "哪次操作", // 贯穿全链路, 一次业务操作生成一次，后续 HTTP、Socket、任务回执继续携带同一个值。
		server: "哪个系统",
		step: "哪个步骤",
		status: "结果", // `started / succeeded / failed`
		error: string | { code: string, msg: string },
		timestamp: "发生时间",
		durationMs: "处理时间",
		payload: {
			input: {},
			output: {},
			data: {}
		}
	}
```

上报方式可以是存到队列中，批量上报。
