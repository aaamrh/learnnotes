
# 纸感手绘新粗野主义科技工作台

目标用户：[用户类型]
核心任务：[用户进入页面后主要完成什么]
平台：[桌面端 / Web / 移动端]

一、风格定位

采用以下视觉语言：

- Paper-tech
- Hand-drawn Neo-Brutalism
- Technical Workflow Schematic
- Modern Productivity Workbench

整体应像“工程草稿纸、技术流程图与现代生产力软件”的结合。

界面需要专业、清晰、紧凑，带有轻微手绘感，但不能幼稚、杂乱或过度卡通化。

这是生产力工具，不是营销落地页。第一屏直接呈现真实、可操作的核心界面，不设计 Hero、大标题或功能宣传区域。

二、画布与色彩

使用温暖的纸张白作为主背景：

- 纸张白：#FBFAF6
- 主墨色：#302D2F
- 次级文字：#6F6A6C
- 状态蓝：#7797F4
- 强调黄：#F5C84C
- 成功绿：#4FC96A
- 数据青：#54C7D3
- 操作珊瑚红：#FF6F72
- 浅蓝选中背景：#E6ECFF
- 浅绿成功背景：#DEF8E5

背景可加入细密、低对比度的点阵网格，形成工程图纸质感。

颜色必须承担明确语义，不为了装饰随意使用彩色。

三、结构与边界

使用清晰的分栏、描边和留白组织界面。

主要区域通过实线或虚线边界分隔，不把每个区域都做成悬浮卡片。

组件遵循以下特征：

- 1.5px 至 2px 近黑色实线边框
- 0 至 3px 小圆角
- 2px 至 5px 硬偏移阴影
- 不使用柔和扩散阴影
- 选中项使用浅蓝背景、深色描边和明显硬阴影
- 状态标签使用紧凑的矩形 Badge，避免胶囊化
- 图标放在具有语义颜色的方形容器中
- 滚动条清晰可见，可使用黄色或其他高对比度滑块

界面应像经过整理的技术工作台，而不是由大量卡片拼成的 SaaS Dashboard。

四、排版

排版紧凑、克制，依靠字重、边框、颜色和布局建立层级。

推荐字体：

- 中文与主要界面：Maple Mono NF CN 优先
- 正文回退：Manrope、Segoe UI 或类似人文无衬线字体
- 状态、编号、模型名称、时间和元数据：JetBrains Mono 或等宽字体
- 品牌名称可以带轻微手写感或不完全规则感

要求：

- 标题尺寸克制
- 字符间距为 0
- 不使用巨大标题
- 元数据尺寸较小但必须清晰可读
- 动态文字不能造成按钮或布局跳动

五、布局原则

根据产品真实业务结构组织界面，不强制套用固定模板。

优先采用生产力工作台布局，例如：

- 导航区
- 工具栏
- 状态区
- 主工作区
- 属性或详情区
- 活动记录区

信息密度可以较高，但必须保持清楚的视觉层级。

频繁操作应位于稳定、可预测的位置。长内容区域可以独立滚动，标题和关键操作保持可见。

流程、节点或连接线只能用于表达真实业务关系，不能为了装饰而添加。

六、交互质感

交互模拟纸张上的实体控件：

- 悬停时最多移动 1px，或轻微改变硬阴影
- 点击时缩小阴影并产生实体按压感
- 选中状态必须明显
- 当前执行节点可以使用轻量脉冲或连线动画
- 加载动画应短促、克制
- 支持减少动态效果

不使用漂浮动画、视差、粒子背景或大面积光效。

七、严格禁止

禁止出现：

- 玻璃拟态
- 半透明浮动面板
- 紫色渐变背景
- 模糊光球、辉光 Orb 或 Bokeh
- 大面积圆角卡片
- 柔和扩散阴影
- 深蓝色 SaaS 仪表盘风格
- 卡片嵌套卡片
- 营销 Hero
- 巨大宣传标题
- 无真实功能的节点画布
- 纯装饰连接线
- 过度卡通化的手绘效果
- 为了追求风格而牺牲可读性

八、设计目标

最终界面应同时具备：

- 工程图纸般的结构感
- 纸张与实体按钮的触感
- 新粗野主义的清晰边界
- 现代桌面软件的专业性
- 高信息密度生产力工具的可扫描性

风格应该服务于产品功能，而不是覆盖产品功能。

保留产品提供的业务流程、信息架构和核心交互，只使用上述设计语言重新表达视觉。
