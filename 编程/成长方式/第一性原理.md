# 第一性原理

相关笔记：[[内功修炼]]、[[思考]]

> [!summary] 用途
> 当脑中出现“必须、只能、没办法、大家都是这样”时，用这套方法区分真正必要条件与当前方案，再从基础重新构造方案。

## 一句话定义

> 不从现成方案出发。先明确真正目标，只保留有证据的信息和必须保留的条件，再从这些基础重新构造方案。

第一性原理不是“自己大胆想”，也不是机械地追问五次为什么。

它不能从空气中产生专业知识。缺少基础知识时，正确动作是查证、测量或实验，不是继续空想。

## 五种内容不要混淆

| 类型 | 含义 | 判断问题 |
| --- | --- | --- |
| 目标 | 最终真正想得到的结果 | 换一种实现方式后，我仍然想要这个结果吗？ |
| 已验证信息 | 当前有观察、测量或可靠知识支持的信息 | 我怎么知道？证据是什么？ |
| 必须保留的条件 | 本次问题中不能违反的物理、安全、法律或明确边界 | 删除它会让任务变质、违法、危险或物理上不可能吗？ |
| 假设 | 尚未证明，但当前结论依赖它 | 如果它是错的，我的结论会不会倒塌？ |
| 当前方案 | 现在想到的一种实现方式 | 它是目标本身，还是众多方案之一？ |

> [!important] 假设不是必填项
> 不要凭空添加假设。只有当前结论依赖某个尚未验证的判断时，才把它写成假设。

## “必须保留的条件”是什么

“硬约束”容易让人误以为它永远不能改变。这里统一使用“必须保留的条件”。

它表示：**在这次问题的范围内，我们决定不改变它。**

常见来源：

```text
物理限制：方案不能违反客观物理限制。
安全限制：不能用明显危害身体的方式换取进度。
法律限制：方案不能违法。
任务定义：要求传输完整文件，就不能擅自丢失内容。
明确边界：本次预算不超过1000元；本次不减少睡眠。
```

检查方法：

```text
如果改变它，只是方案不同或稍微不方便，它不是必须保留的条件。
如果改变它，会改变任务、越过明确底线或让方案不成立，它才是。
```

## 假设有什么作用

假设不负责提供答案。它负责暴露当前结论最脆弱的位置。

例句：

```text
我必须每天早起一小时，才能每周学习五小时。
```

为了让“必须早起”成立，至少有一个判断必须为真：

```text
除早晨之外，没有其他五小时可以使用。
```

如果日历中能找到其他五小时，这个判断就是错的，“必须早起”也随之倒塌。

提取假设时只问：

> **为了让当前方案成为唯一方案，什么必须为真？我有证据吗？**

与当前结论无关的假设，不要写。

## 执行步骤

```text
1. 写出一句真实的“必须、只能、没办法”。
2. 把真正目标与当前方案分开。
3. 只列有证据支持的信息，并注明证据。
4. 列出本次必须保留的条件，并写明来源。
5. 反推当前方案依赖哪些未经验证的判断。
6. 把其余内容恢复成可以改变的变量。
7. 仅使用目标、证据和必要条件，重新构造方案。
8. 用最低成本、可撤回的行动验证新方案。
9. 根据结果更新信息、条件或方案。
```

## 完整案例：每周学习五小时

### 原始判断

```text
我必须周一到周五每天早起一小时，才能每周学习五小时。
```

### 真正目标

```text
每周完成300分钟学习。
```

早起不是目标，只是当前方案。

### 已验证信息

假设下面数据来自实际日历：

```text
周一、周三、周五午休各有30分钟：90分钟
周六上午可用120分钟
周日下午可用90分钟
合计：300分钟
```

### 必须保留的条件

```text
不能占用固定工作时间。
本次不减少睡眠。
家庭安排已经锁定的时段不改。
```

这些条件来自明确边界，不是宇宙真理。

### 当前方案

```text
工作日每天早起一小时。
```

### 当前方案依赖的假设

```text
假设一：早晨是唯一可用时间。
假设二：五小时必须平均分到五天。
假设三：每次学习必须连续一小时。
```

日历已经否定假设一。目标本身也没有要求假设二和三成立。

### 从基础重新构造

```text
周一、三、五午休：90分钟
周六上午：120分钟
周日下午：90分钟
总计：300分钟
```

### 最小验证

执行一周，只记录：

```text
计划300分钟，实际完成多少分钟？
是否影响工作、睡眠和家庭安排？
哪些纸面可用时间在现实中不可用？
```

如果只完成150分钟，就把“这些时段真实可用”从已验证信息降级为假设，再重新安排。

> [!warning] 能力边界
> 这个分析只能解决“如何安排五小时”。它不能凭空判断“什么学习方式最有效”。后者需要具体领域知识，并通过 [[内功修炼]] 中的真实训练闭环验证。

## 最小使用规则

1. 只拆真实存在的判断，不编稻草人假设。
2. 每条“已验证信息”都写证据来源。
3. 每条“必须保留的条件”都写为什么不能改。
4. 只提取当前结论真正依赖的假设。
5. 缺少专业知识时停止推导，先补证据。
6. 新方案必须进入现实验证，不能只停留在纸面。
