
## 一、先说结论

这一轮不是简单的“GPU涨完，设备接棒，设备涨完，耗材接棒”。半导体产业同时运行着几只不同的钟：

1. **产品价格周期**：缺货和涨价最先反映到芯片、存储和元器件利润中。
2. **晶圆厂稼动率周期**：现有产线提高产量后，抛光液、靶材、电子特气等耗材立即增加。
3. **资本开支周期**：扩产形成设备订单，收入还要等待交付、调试和验收。
4. **股票定价周期**：股价通常提前交易未来利润，也可能在财报最漂亮时开始见顶。

因此，设备和高端耗材不是严格的先后关系。现有晶圆厂提高稼动率，会先增加耗材消耗；新建晶圆厂扩产，则先形成设备订单，投产后再形成新增耗材需求。

当前大致处在：

> **AI芯片、HBM、高速光模块和AI PCB利润已经充分兑现；先进制程继续扩产；半导体设备与高端耗材共同进入利润加速期；高端MLCC出现供需趋紧迹象；通用湿电子化学品和大硅片尚未形成全面利润拐点。**

### 8. 高端半导体耗材

#### 8.1 先统一“高端耗材”的口径

本文对狭义高端耗材使用六项标准：

1. 每生产一批晶圆都要持续消耗；
2. 纯度、配方或一致性要求极高；
3. 客户认证周期较长；
4. 认证后客户不会轻易更换；
5. 工艺复杂度提升会增加单位晶圆用量或价值量；
6. 竞争不只是依靠扩产和低价。

根据这个标准，应区分三类产品：

| 类别 | 典型产品 | 是否属于本文所说的高端耗材 |
|---|---|---|
| 狭义工艺耗材 | CMP抛光液、抛光垫、前驱体、电子特气、靶材、光刻胶 | 是 |
| 消耗型零部件 | 石英件、陶瓷件、硅零部件 | 广义上是，商业模式介于耗材和零部件之间 |
| 晶圆衬底材料 | 12英寸硅片、外延片 | 会持续采购，但重资产、标准化和价格周期更强，不纳入狭义高端工艺耗材 |

这就解决了原来的口径冲突：

- **中巨芯是半导体耗材公司，但目前不能把整家公司视为高端耗材龙头。**其部分特气和前驱体是高端产品，收入主体仍以湿电子化学品为主。
- **西安奕材当然属于半导体材料，也会被持续消耗，但它是晶圆衬底厂，不是本文狭义定义的高端工艺耗材公司。**
- **国瓷材料是电子陶瓷材料公司，MLCC介质粉体属于元器件上游材料，不属于晶圆制造耗材。**

## 四、历史周期如何“押韵”

### 1. 2017年：设备与材料可以同时景气

2017年全球半导体设备销售额增长37%，同期硅片出货增长10%、销售额增长21%。这说明设备和材料常常重叠赚钱，并不存在固定的一年期接力。

- [SEMI：2017年全球设备销售数据](https://www.semi.org/en/Global-Equipment-Sales-56-6-Billion)
- [SEMI：2017年硅片出货与收入数据](https://www.semi.org/en/annual-silicon-volume-shipments-remain-record-highs-1)

### 2. 2020年至2023年：业绩最好不等于股价最安全

- 全球设备销售额2020年增长19%，2021年增长44%，2022年继续创1076亿美元纪录。
- 硅片2021年出货量和销售额同步增长，2022年出货创纪录。
- 2023年终端需求和库存转弱后，硅片出货下降14.3%，设备销售也进入调整。

设备从订单到交付验收存在滞后，因此在终端周期接近顶部时，设备公司仍可能报告漂亮利润。判断设备周期不能只看当期业绩，还要领先观察晶圆厂资本开支和新订单。

- [SEMI：2021年全球设备销售数据](https://www.semi.org/en/news-media-press-releases/semi-press-releases/2021-global-semiconductor-equipment-sales-surge-44%25-to-industry-record-%24102.6-billion-semi-reports)
- [SEMI：2022年全球设备销售数据](https://www.semi.org/en/news-media-press-releases/semi-press-releases/global-semiconductor-equipment-billings-reach-industry-record-%24107.6-billion-in-2022-semi-reports)
- [SEMI：2023年硅片市场数据](https://www.semi.org/en/news-media-press-releases/semi-press-releases/worldwide-silicon-wafer-shipments-and-revenue-fall-in-2023-semi-reports)

### 3. 本轮与历史的相同和不同

相同之处：

> 需求爆发或缺货涨价形成芯片利润，晶圆厂提高稼动率带动耗材，扩产带动设备，新增供给最终又可能形成过剩。

不同之处：

- 本轮主要由AI、HBM和先进制程驱动，不是手机、PC、汽车等所有需求同步繁荣。
- 高端工艺材料可能很强，但通用化学品、大硅片和传统消费芯片仍可能较弱。
- 先进制程增加工艺步骤，使单位晶圆对应的沉积、刻蚀、清洗、CMP和量检测价值量提高。
- 国产替代是独立于全球周期的第二条增长线，但国产替代也不能消除扩产过剩和价格竞争。

## 五、后续机会怎么排序

### 未来6至12个月：优先看利润扩散

1. **高端耗材：**安集科技 `688019`、鼎龙股份 `300054`、江丰电子 `300666`、中船特气 `688146`。重点是已经有收入、利润和现金流验证的CMP、靶材和电子特气，而不是所有化学品。
2. **半导体设备：**中微公司 `688012`、拓荆科技 `688072`、华海清科 `688120`、中科飞测 `688361`。产业确定性高，但要结合订单、验收和估值判断，不能默认仍在低位。
3. **高端MLCC：**三环集团 `300408`、风华高科 `000636`。这是供需驱动的旁支机会，必须等待实际提价、产品结构和毛利率验证。

### 未来1至3年：优先看资本开支与国产化

- 刻蚀、沉积、清洗、CMP和量检测设备；
- CMP材料、前驱体、电子特气、靶材及腔体消耗件；
- 先进封装设备、材料和晶圆级封装产能。

### 暂时不把“没涨”当成机会

- **大硅片：**等待ASP、稼动率和毛利率共同反转。
- **通用湿电子化学品：**等待高端产品占比、吨毛利和现金流改善。
- **中巨芯：**等待特气和前驱体成为真实利润主体，而不只是题材映射。
- **西安奕材：**等待亏损收窄和硅片价格拐点，不能简单套用安集、鼎龙的估值逻辑。

## 六、最重要的跟踪框架

| 板块       | 不要只看          | 更应该看                     |
| -------- | ------------- | ------------------------ |
| GPU、AI芯片 | 收入增速          | 产品迭代、软件生态、毛利率、供应能力和估值    |
| HBM映射    | 公司是否说“可用于HBM” | 是否量产、客户是谁、相关收入占比、利润贡献    |
| 存储模组     | 存储涨价          | 库存成本、存货周转、现金流和跌价准备       |
| 光模块、PCB  | AI订单          | 产品代际、客户集中度、产能扩张和高基数      |
| 设备       | 当期净利润         | 新签订单、合同负债、验收、现金流和晶圆厂资本开支 |
| 高端耗材     | 国产替代概念        | 高端产品收入占比、毛利率、客户认证和重复采购   |
| MLCC     | 缺货传闻          | 订单出货比、交期、实际提价和高端型号占比     |
| 大硅片      | 出货量           | ASP、稼动率、毛利率、折旧和经营现金流     |

最终应记住一句话：

> **历史重复的不是板块上涨顺序，而是利润形成机制。不要因为一个板块没有上涨，就认定它必然是下一棒；先判断需求是否增加、价格是否改善、利润能否进入报表，再判断市场是否已经提前定价。**
