# 中远海控：周期监控与投资清单

> 更新日期：2026年9月18日  
> 标的：中远海控 `601919`。主营集装箱航运和码头，不是油轮公司。  
> 定位：周期红利卫星仓，不作为稳定红利核心仓。

## 一、核心结论

中远海控利润公式：

```text
箱量 × 单箱运价 - 船舶、燃油、港口、租船、保险等成本
```

影响强弱排序：

1. **集装箱运价**：影响最大。
2. **全球货运需求**：决定箱量及运价能否持续。
3. **全球船队供给和有效运力**：决定运价中期方向。
4. **燃油、战争保险和航道中断**：短期影响大，方向取决于运价能否覆盖成本。
5. **人民币汇率和美国利率**：次要变量。

不看或少看：

- `CPI`：反映价格，不直接反映需要运输多少箱货。
- `BDI`：干散货指数，与集装箱航运不是同一市场。
- 油轮运价：更直接影响中远海能 `600026`，不是中远海控。
- 港口总吞吐量：必须剔除空箱，优先看重箱进口量。

## 二、监控权重

以下权重用于日常跟踪，属于实用判断框架，未做统计回测。

| 模块 | 权重 | 核心数据 | 上涨/改善 | 下跌/恶化 |
|---|---:|---|---|---|
| 运价 | **40%** | CCFI、SCFI、SCFIS | 利好 | 利空 |
| 全球及欧美需求 | **20%** | 全球港口吞吐量、美国重箱进口、ISM进口、库存销售比 | 利好 | 利空 |
| 船队供给及有效运力 | **25%** | 全球船队、订单、交付、准班率、港口等待 | 需求快于供给利好 | 供给快于需求利空 |
| 燃油及地缘风险 | **10%** | 燃油、战争险、红海/霍尔木兹通行 | 运价涨幅覆盖成本才利好 | 长期封锁及成本失控利空 |
| 汇率及利率 | **5%** | USD/CNY、美元利率 | 视净敞口而定 | 影响次于运价和需求 |
| **合计** | **100%** |  |  |  |

评分方法：每项按 `+2 / +1 / 0 / -1 / -2` 评分。

```text
总分 = Σ（模块权重 × 模块评分 ÷ 2）
```

| 总分 | 周期判断 |
|---:|---|
| `≥ +30` | 景气向上，可持有或按计划增加卫星仓 |
| `-30 至 +30` | 混合区，不追涨 |
| `≤ -30` | 景气向下，减少或回避周期仓 |

## 三、运价：40%

### 1. CCFI：25%

查询：[中国出口集装箱运价指数 CCFI](https://www.sse.net.cn/index/singleIndex?indexType=ccfi)，每周五发布。

CCFI覆盖中国出口整体市场，包含即期和长期合同价，最接近中远海控实际收入趋势。

重点看：

- 综合指数
- 美西、美东
- 欧洲、地中海
- 波斯湾/红海

判断：

- 四周均值高于十三周均值且继续上升：`+1 至 +2`
- 连续四周下降：`-1`
- 同比和环比同时下降：`-2`

截至2026年9月11日：

| CCFI | 周涨跌 |
|---|---:|
| 综合指数 | `+1.4%` |
| 美西 | `+1.7%` |
| 美东 | `+0.5%` |
| 欧洲 | `-2.2%` |
| 地中海 | `+0.9%` |
| 波斯湾/红海 | `+3.0%` |

当前：整体反弹，欧洲仍弱，记 `+1`。

### 2. SCFI、SCFIS：15%

- [SCFI上海出口即期运价](https://www.sse.net.cn/index/singleIndex?indexType=scfi)：每周五；反应快、波动大。
- [SCFIS上海出口结算运价](https://www.sse.net.cn/index/singleIndex?indexType=scfis)：每周一；看实际结算价，主要覆盖欧洲和美西。

组合判断：

| 状态 | 含义 |
|---|---|
| SCFI先涨、CCFI未涨 | 即期反弹，尚未传导至整体收入 |
| SCFI、SCFIS、CCFI同时上涨 | 最强运价利好 |
| SCFI上涨、SCFIS不涨 | 报价上涨但实际成交未确认 |
| 三者连续下降 | 明确利空 |

截至2026年9月11日，SCFI从3590.05升至3662.18，周涨约2.0%。

## 四、全球及欧美需求：20%

### 1. 全球集装箱吞吐量：8%

查询：[RWI/ISL全球集装箱吞吐量指数](https://www.isl.org/en/services/rwiisl-container-throughput-index)，每月发布，覆盖约90个港口、约64%全球吞吐量。

- 三个月趋势持续上涨：利好。
- 三个月趋势持续下降：利空。
- 运价上涨、吞吐量下降：多为战争、拥堵造成的供给冲击，持续性较差。

2026年7月：142.7降至142.5，基本横盘，记 `0`。

### 2. 美国重箱进口：7%

查询：

- [洛杉矶港月度重箱进口](https://portoflosangeles.org/business/statistics/container-statistics/historical-teu-statistics-2026)
- [长滩港贸易统计](https://polb.com/business/port-statistics/)

只看 `Loaded Imports`，使用三个月同比均值：

| 三个月同比 | 判断 |
|---:|---|
| `> +5%` | 利好 |
| `-3% 至 +3%` | 中性 |
| `< -5%` | 明显利空 |

按官网重箱进口量自行同比计算，洛杉矶港2026年1至8月累计`+2.20%`；6月`+12.78%`、7月`-8.12%`、8月`-0.84%`，最近三个月合计`+0.77%`。美国进口未崩，但动能接近横盘。

欧洲辅助看：

- [鹿特丹港集装箱吞吐量](https://www.portofrotterdam.com/en/logistics/port-performance)
- [Eurostat欧盟进口量](https://ec.europa.eu/eurostat/web/international-trade-in-goods/information-data)

### 3. 美国领先指标：5%

- [ISM制造业Imports指数](https://www.ismworld.org/supply-management-news-and-reports/reports/ism-pmi-reports/pmi/august/)：`>50`进口扩张，`<50`进口收缩。
- [美国零售库存/销售比](https://fred.stlouisfed.org/series/RETAILIRSA)：库存月数。

库存比必须结合销售和进口判断：

- 库存比持续上升、销售不强：积压，未来减少进口，利空。
- 库存比处于低位、销售稳定：可能补库存，利好。

2026年8月ISM Imports为52.5，仍扩张，但低于7月55.7。2026年7月零售库存/销售比由1.25升至1.27。合计记 `0`。

## 五、船队供给及有效运力：25%

### 1. 全球船队和订单：15%

查询：[Alphaliner Top 100](https://alphaliner.axsmarine.com/PublicTop100/)。

重点字段：

- `Existing fleet`：现有运力。
- `Orderbook`：在建订单。
- `Orderbook % existing`：订单占现有船队比例。

订单比例越高，未来运力压力越大。订单不会立刻形成供给，需要结合交付年份。

截至2025年底参考值：

- 全球船队约3330万TEU。
- 在手订单约1130万TEU，约占现有运力34%。
- 2026年预计交付约140万TEU。
- 2026年集运需求预计增长约2.5%。

来源：[ZIM 2025年报引用Alphaliner数据](https://d18rn0p25nwr6d.cloudfront.net/CIK-0001654126/7c68d4e0-3056-4399-bcb9-6f913e69763f.html)。中期供给压力偏大，记 `-1`。

### 2. 供需差：5%

```text
供需差 = 全球船队TEU同比增速 - 全球集装箱货量同比增速
```

| 供需差 | 判断 |
|---:|---|
| `< 0` | 需求快于供给，利好运价 |
| `0 至 2个百分点` | 基本平衡 |
| `> 2个百分点` | 运力过剩，利空 |
| `> 5个百分点` | 严重运力压力 |

### 3. 有效运力：5%

查询：[GCSP全球班轮准班率及港口时间](https://en.sse.net.cn/indices/gcspi_portadvancenew.jsp)，每月发布。

- 准班率下降、港口等待上升：船被占用，有效运力下降，短期支撑运价。
- 准班率恢复、等待下降：运力释放；新船又多时，利空运价。
- 准班率下降但CCFI不涨：只有成本上升，不构成利好。

## 六、燃油及地缘风险：10%

### 霍尔木兹海峡

查询：[IMO霍尔木兹专题和通行数据](https://www.imo.org/en/mediacentre/hottopics/pages/middle-east-strait-of-hormuz.aspx)。

| 情景 | 运价 | 成本/货量 | 对中远海控净影响 |
|---|---|---|---|
| 风险上升但仍可通行 | 附加费上涨 | 保险、燃油上涨 | 混合 |
| 短期部分受阻 | 有效运力减少，运价可能上涨 | 海湾货量减少 | 混合，取决于涨价能否覆盖成本 |
| 长期完全封锁 | 其他航线可能涨价 | 海湾港口无法绕行、货量中断、能源成本激增 | **明显利空** |

红海可以绕好望角；波斯湾港口无法绕过霍尔木兹。不能把“封锁”简单视为航运股利好。

截至2026年9月16日，IMO确认霍尔木兹及附近发生80起针对国际航运的袭击，至少22名船员死亡。中远海控已利用阿曼湾安全港口和阿布扎比枢纽构建替代网络。

### 燃油和战争险

- 燃油上涨：直接利空成本。
- CCFI/SCFI已包含部分燃油、战争、拥堵等附加费；指数涨幅大于成本涨幅时，船公司才可能净受益。
- 燃油上涨但CCFI不涨：明确利空。

## 七、汇率及美国利率：5%

### 人民币汇率：3%

人民币升值通常轻度利空人民币报表：

- 美元运费换成更少人民币：利空。
- 美元现金折算缩水：利空。
- 美元燃油、港口、租船成本下降：利好，形成部分对冲。

2026年上半年平均美元兑人民币由7.1793降至6.9043。同期航线收入按美元增长4.92%，按人民币只增长0.90%。

结论：人民币升值偏利空，但影响远小于运价。

### 美国利率：2%

中远海控净现金多。公司披露，利率上升0.5个百分点，税后利润约增加4.54亿元，直接财务影响偏利好。

更重要的是间接影响：

- 温和加息、美国进口仍增长：中性至轻度利好。
- 加息引发消费、库存和进口下降：通过运价形成明显利空。

因此不要直接用“美联储加息”判断中远海控，最终仍看美国重箱进口和CCFI。

来源：[中远海控2025年报，财务风险敏感性](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0424/2026042401981.pdf)。

## 八、公司财报：最终确认，不重复计权

每次半年报、年报检查：

1. 国际航线 `Revenue per TEU` / 单箱收入。
2. 集运业务 `EBIT margin`。
3. 箱量。
4. 经营现金流。
5. 每股分红。

判断：

| 单箱收入 | EBIT利润率 | 结论 |
|---|---|---|
| 上升 | 上升 | 最强确认 |
| 上升 | 下降 | 成本上涨更快，谨慎 |
| 下降 | 上升 | 降本暂时抵消运价压力 |
| 下降 | 下降 | 明确利空，周期未改善 |

2026年上半年：

- 箱量同比`+7.52%`。
- 国际航线单箱收入同比约`-2.1%`。
- 集运EBIT利润率：`20.52% → 14.15%`。
- 归母利润同比约`-23.6%`。
- 中期每股分红：`0.56元 → 0.43元`，同比约`-23.2%`。

结论：箱量增长未转化为利润增长，财报确认信号仍为负面。

来源：[中远海控2026年中报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0828/2026082803772.pdf)。
